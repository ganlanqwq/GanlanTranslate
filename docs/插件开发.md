# 插件开发

甘岚翻译 1.1.0 起支持插件。插件是一个 `.zip` 包，里面有记录信息的 `plugin.json` 和可选的 Python 代码，放在程序目录的 `plugins` 文件夹里。

- 安装：把 zip 拖进甘岚翻译窗口（哪一页都行），或者在「插件」页点「导入插件」。也可以直接把 zip 复制进 `plugins` 文件夹，再点「刷新」。
- 管理：「插件」页可以启用 / 禁用、改设置、删除；「信息 → 软件信息」里能看到装了哪些插件，并打开插件文件夹。
- 示例：[`plugin-example/`](plugin-example/)（聊天框前后缀）。把里面的文件压成 zip 就是一个能用的插件。

> 插件里的代码和甘岚翻译在同一个进程里运行，能做程序本身能做的任何事。只安装你信任的插件。

## 包的结构

```
my-plugin.zip
├── plugin.json   必须有
├── main.py       入口（默认 main.py，可以在 plugin.json 里改）
├── icon.png      可选，插件列表里显示的图标
└── ...           其他 .py 文件、数据文件
```

`plugin.json` 要放在压缩包根目录；如果打包时多包了一层文件夹（`my-plugin/plugin.json`），也能认出来。插件不会被解压，代码直接从 zip 里加载。

开发时可以不打包：在 `plugins` 里建一个文件夹，放进 `plugin.json` 和代码，点「刷新」就会加载。改了代码后，把插件禁用再启用即可重新加载。

## plugin.json

```json
{
  "id": "chatbox-decorator",
  "name": { "zh-CN": "聊天框前后缀", "en": "Chatbox Prefix & Suffix" },
  "version": "1.1.0",
  "author": "甘岚",
  "description": "在你说的每句话前后加上自定义内容，翻译时一起翻译。",
  "homepage": "https://github.com/...",
  "entry": "main.py",
  "icon": "icon.png",
  "min_app_version": "1.1.0",
  "settings": []
}
```

| 字段 | 说明 |
|---|---|
| `id` | 必填。字母、数字和 `. _ -`，以字母或数字开头，最多 64 个字符。同一个 id 只能装一个，导入同 id 的新包会提示替换（设置保留）。 |
| `name` | 必填。字符串，或者按界面语言给的 `{ "zh-CN": ..., "en": ..., "ja": ..., "ko": ... }`。 |
| `version` | 版本号，显示在列表里。 |
| `author` / `description` | 可选，同样可以按语言给。 |
| `homepage` | 可选，`http://` 或 `https://` 开头的链接。 |
| `entry` | 可选，入口 `.py` 文件的路径（相对插件根目录）。不写时有 `main.py` 就用它，没有就是不含代码的插件。 |
| `icon` | 可选，`.png` / `.jpg` / `.webp` / `.gif`，不超过 512 KB。 |
| `min_app_version` | 可选，需要的最低甘岚翻译版本，版本不够时插件不会启用。 |
| `settings` | 可选，设置项列表，见下面。 |

`name`、`description`、设置项的 `label` 等文字都可以写成按语言的对象，界面会按当前语言挑；没有当前语言时依次用简体中文、英文、第一个。

## 设置项

在「插件」页点齿轮按钮会展开这个插件的设置，表单按 `settings` 生成。保存时会按类型检查，存在 `plugins\_config.json` 里（替换插件时保留，删除插件时一起删除）。

```json
"settings": [
  { "key": "prefix", "type": "text", "label": "前缀", "default": "" },
  { "key": "partial", "type": "toggle", "label": "说话中的半句也加", "default": false },
  { "key": "max_length", "type": "number", "label": "最多几个字", "min": 0, "max": 40, "step": 1, "default": 20 },
  { "key": "position", "type": "select", "label": "放在哪里",
    "options": [ { "value": "inline", "label": "同一行" }, { "value": "newline", "label": "另起一行" } ],
    "default": "inline" }
]
```

| type | 值 | 额外字段 |
|---|---|---|
| `text` | 字符串 | `max_length`（默认 2000） |
| `password` | 字符串（输入框里显示成圆点） | `max_length` |
| `textarea` | 多行字符串 | `max_length`（默认 20000） |
| `number` | 数字 | `min`、`max`、`step` |
| `toggle` | `true` / `false` | |
| `select` | 选中项的 `value` | `options`：字符串列表，或 `{ "value", "label" }` 列表 |

每项都可以有 `label`（显示的名字）、`description`（下面的小字说明）和 `default`。`key` 只能用字母、数字、下划线。

注意：`password` 类型的值也是明文存在 `plugins\_config.json` 里的。

## 入口里的函数

入口模块里可以定义下面这些函数，都是可选的，用不到的不写。

```python
ctx = None

def setup(context):              # 启用时（程序启动、导入、在网页上启用）
    global ctx
    ctx = context

def teardown():                  # 禁用、删除、替换、退出前
    pass

def on_settings_changed(settings):   # 网页上保存了设置，settings 是新的设置字典
    pass

def filter_source(text):         # 自我识别出一整句、还没翻译之前
    return None                  # None = 不改；返回字符串 = 换成它（拿它去翻译）；"" = 这句不要

def filter_chatbox(text, ongoing):   # 发到 VRChat 聊天框之前
    return None                  # None = 不改；返回字符串 = 换成它；"" = 这句不发

def on_self_result(event):       # 自我翻译出了一句终句
    pass

def on_others_result(event):     # 他人翻译出了一句
    pass

def on_screen_result(event):     # 翻译画面完成一次
    pass
```

- `filter_source` 只处理自我翻译的终句（说话中的半句不经过它），改过的文字就是之后翻译、上悬浮窗、发聊天框用的原文，所以加进去的内容会跟着一起翻译。返回 "" 时这句当作没说过：不翻译、不发，「正在输入」也会关掉。它在识别线程里直接调用，要尽量快，超过 0.2 秒日志里会提醒。
- 想加的东西不要翻译（比如表情、签名）就用 `filter_chatbox`；想跟着一起翻译就用 `filter_source`。示例插件两个都用了：整句在 `filter_source` 里加前后缀，`filter_chatbox` 只给说话中的半句加（半句不翻译）。
- `filter_chatbox` 在发送的线程里直接调用，`ongoing=True` 是说话中的半句（会很频繁），要尽量快；超过 0.2 秒日志里会提醒。装了多个插件时按插件名字的顺序依次处理。插件自己用 `ctx.send_chatbox()` 发的文字不经过这里。
- `on_*_result` 在插件专用的后台线程里按顺序调用，慢一点不会耽误翻译。
- 函数出错只会打印到「运行日志」（同一个插件连续出错 5 次后不再打印），不会影响翻译；`setup` 出错时插件显示为「出错」，可以禁用再启用来重试。

### 事件内容

`on_self_result(event)`：

| 键 | 说明 |
|---|---|
| `source` | 识别出来的原文（`filter_source` 处理之后） |
| `source_lang` | 原文语言 |
| `translation` | 译文（只识别不翻译时是空字符串） |
| `target_lang` | 译文语言 |
| `secondary_translation` / `secondary_lang` | 开了第二目标语言时的第二译文 |
| `chatbox` | 实际要发到聊天框的文字（`filter_chatbox` 处理之前） |
| `time` | 时间戳（秒） |

`on_others_result(event)`：`speaker`（说话人字母）、`source`、`source_lang`、`translation`、`target_lang`、`time`。

`on_screen_result(event)`：`target_lang`、`items`（每段 `{ "original", "lang", "translated" }`）、`time`。

## ctx

`setup(ctx)` 收到的对象：

| 属性 / 方法 | 说明 |
|---|---|
| `ctx.id` | 插件 id |
| `ctx.name` | 插件名字（当前语言） |
| `ctx.settings` | 当前设置（字典副本，每次读都是最新的） |
| `ctx.data_dir` | 插件自己写文件的文件夹 `plugins\_data\<id>`，第一次用时创建；删除插件时一起删除 |
| `ctx.app_version` | 甘岚翻译版本号 |
| `ctx.ui_language` | 当前界面语言（`zh-CN` / `en` / `ja` / `ko`） |
| `ctx.log(...)` | 写一行到网页「运行日志」，前面带 `[插件:名字]` |
| `ctx.send_chatbox(text)` | 往 VRChat 聊天框发一句 |

## 导入别的模块

- 插件里的其他文件用相对导入：`from . import helper`、`from .utils import foo`。
- 安装版里只能 import 程序自带的模块：Python 标准库的常用部分（`json`、`re`、`csv`、`sqlite3`、`urllib.request`、`datetime`、`threading` 等），以及程序本身用到的第三方库（如 `requests`）。
- 其他纯 Python 的库可以连同源码一起放进插件包，再用相对导入。带 `.pyd` / `.dll` 的库不能从 zip 里加载。

## 文件位置

| 位置 | 内容 |
|---|---|
| `plugins\*.zip` | 插件包 |
| `plugins\<文件夹>\plugin.json` | 开发中的插件（没打包） |
| `plugins\_config.json` | 每个插件是否启用、设置 |
| `plugins\_data\<id>\` | 插件自己的数据 |

安装版的 `plugins` 在安装目录里（默认 `C:\Program Files (x86)\Ganlan Translate\plugins`），覆盖升级不会动它。
